## Обзор

Поле Remix выводит преобразованное значение вашего заголовка или слага на основе определенных вами правил, включая:

 - Поиск и замена (с поддержкой регулярных выражений)
 - Преобразования в верхний регистр, нижний регистр и регистр заголовка
 - Добавление текста в конец
 - Добавление текста в начало

### Возможности
 - **Предварительный просмотр в реальном времени** - тестируйте свои правила в реальном времени с пошаговой разбивкой по правилам
 - **Встроенная валидация регулярных выражений** - видите ошибки по мере ввода шаблонов
 - **Регулярные выражения** - для поиска и замены
 - **Игнорирование регистра** - для поиска и замены
 - **Шаблонные правила** - быстрое добавление типичных шаблонов, таких как удаление артиклей, пунктуации или объединение пробелов
 - **Все типы элементов** - работает с записями, категориями и любыми элементами с заголовком или слагом
 - **Фильтрация и сортировка элементов** - в панели управления

### Варианты использования
Сортировка, фильтрация, перевод, редактирование, форматирование, SEO

## Как использовать
1. Создайте поле Remix
2. Выберите цель (заголовок или слаг)
3. Определите свои правила (или используйте кнопки шаблонов для типичных шаблонов)
4. Добавьте поле в макет полей вашего элемента
5. Remix автоматически заполняется при сохранении элемента

## История создания
Это поле было создано для решения конкретной задачи: удаления "The" и "A" из заголовков для создания поля сортировки. На самом деле, оригинальное название этого плагина было **Sort Title**. Но после некоторых экспериментов стало ясно, что у этого поля есть больше потенциала.

Так родилось поле Remix.

## Обновление до v2.0.0

Версия 2.0.0 включает критические изменения с автоматической миграцией:

- **Имена свойств** изменены с PascalCase на camelCase (например, `RemixTarget` → `target`)
- **Хранение правил** изменено с индексированных массивов на ассоциативные массивы
- **Craft 4 больше не поддерживается** — используйте ветку 0.x для Craft 4

Миграция выполняется автоматически при обновлении. Сначала сделайте резервную копию базы данных.

## Установка

Вы можете установить этот плагин из [Магазина плагинов](https://plugins.craftcms.com/remix) или с помощью Composer.

Требуется Craft CMS 5.0.0 или выше и PHP 8.2 или выше.

### С помощью Composer

```bash
# перейдите в каталог проекта
cd /path/to/my-project.test

# скажите Composer загрузить плагин
composer require mlathrom/craft-remix

# скажите Craft установить плагин
./craft plugin/install remix
```
